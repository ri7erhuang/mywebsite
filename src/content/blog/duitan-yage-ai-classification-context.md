## 关键概念

- **GEV / 分类模型**：只做 classification，输出置信度 / 概率；对应 System 1 / System 2 的分工。
- **Browser Use / Computer Use**：用 DOM tree 做分类，速度约提升 10 倍且更省钱。
- **Harness**：工具调用的安全分类频繁发生，开源 harness 可借此补齐能力。
- **Cloud Computer**：给 AI 一台持久化的云端电脑，保留凭据与记忆。
- **Context Infrastructure**：intake skill、语音识别、Yahoo 式索引、embedding 语义检索；一切皆文件。
- **零人公司 / 一人公司**：AI 自动运营 Newsletter 与 X，做 UTM 归因与文案迭代。
- **蒸馏**：把「勇哥说餐饮」100 个视频蒸出 20 条开餐馆经验并开源 skill。
- **AI 管理**：外化 Context、Prompt、文件和验收标准；不画饼、不担心自尊。
- **多变量回归 / CGM / NFC 咖啡记录**：用于找出影响睡眠的高杠杆变量。

## 可执行建议

> 以下为从讲述中可提炼的行动提示，不代表原视频逐字建议。

- 给 AI 积累 Context：整理本地文件、会议录音、微信 / 邮件记录，用 intake skill 和语义搜索做索引。
- 把 AI 当秘书 / 管理对象：明确任务、成功标准、验收方式，让它沉淀 SOP 并自我迭代。
- 开源 skill 不要追求开箱即用，先在自己的场景跑一遍，把反馈写成文件，逐步「养」成自己的系统。
- 用 AI 做生活自动化：健康数据导出、照片批量归档、保险理赔邮件、活动名单分析。
- 记录个人数据并做简单分析，例如睡眠与晚间 AI 使用时间，找到高杠杆调整点。
- 学 AI 要动手做完整项目；内容创作者先拍满 20 个视频再请教。
- 组织内可尝试把 SOP、leadership principles 写成 prompt / markdown，让 AI 承担确定性执行。
- 对隐私敏感的数据优先本地处理，谨慎把密钥和私密 Context 放到云端。
