欢迎来到我的个人网站。这里会用来放三样东西：

1. **博客** — 记录技术与生活。
2. **导航** — 我常用的网站和工具。
3. **在线工具** — 一些自己在用的小工具。

## 为什么写博客

写作是最好的整理方式。把零散的经验写下来，既能帮到别人，也能帮到未来的自己。

## 技术栈

本站使用 [Astro](https://astro.build) 构建，Tailwind CSS 处理样式，部署在 Cloudflare Pages 上。

```bash
npm run dev     # 本地开发
npm run build   # 构建产物
npm run deploy  # 部署到 Cloudflare
```
